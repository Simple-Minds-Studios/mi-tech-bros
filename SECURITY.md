# Security policy

## Supported versions

Security fixes target the current default branch. Historical branches, prototypes and research demonstrations may not receive independent maintenance.

## Report an issue privately

Use this repository’s **Security → Report a vulnerability** option when available, or email **MITechBros@outlook.com**. Include the affected version, reproduction steps and impact. Do not put credentials, personal records or exploitable details in a public issue.

Do not send private family-history archives or personal-context exports with an initial report. Use fictional or redacted examples.

This policy is a reporting route, not a claim that the project has passed a security audit.
